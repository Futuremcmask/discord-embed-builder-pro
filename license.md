## 🎨 Design Discord Messages Visually

**Discord Embed Builder Pro** is the ultimate drag-and-drop visual editor for creating rich, beautiful Discord message embeds without writing a single line of code. 

If you've ever tried to build a complex Discord embed manually, you know the pain. A missing comma or a misplaced bracket breaks the entire JSON payload. This tool eliminates that frustration. It provides a live WYSIWYG (What You See Is What You Get) editor where you can add titles, descriptions, images, footers, and custom fields with a click of a button.

Once your masterpiece is ready, the app generates the exact **JSON code**, **Discord.js embed objects**, or **webhook payloads** ready to be pasted into your bot or automation platform. It's the essential tool for server admins, bot developers, and community managers who want their announcements to look professional.

> 💡 **Why use this builder?** Because first impressions matter. A beautiful embed gets clicks and reads. A plain text message gets ignored. Elevate your server's aesthetic instantly.

## 🚀 Quick Start

> **Three steps. Under two minutes. No installation required.**

### 1️⃣ Launch the App
Click the **Launch Builder** button at the top of this README to open the web app.

### 2️⃣ Design your Embed
Use the sidebar to add a title, description, and color. Drag fields to reorder them.

### 3️⃣ Export
Click the "Copy Code" button to get the JSON or Discord.js object and paste it into your bot.

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---:|
| 🖥️ **Frontend UI** | Drag-and-drop editor and state | `React` + `Redux` |
| 🎨 **Preview** | Replicates Discord's CSS for accuracy | `TailwindCSS` |
| 📦 **Compiler** | Converts UI state to JSON objects | `TypeScript` |
| 💾 **Storage** | Saves drafts locally | `LocalStorage` |

</div>

The builder uses a custom JSON schema that mirrors Discord's official embed structure. When you hit export, it simply serializes the state into the exact format the Discord API expects.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is it really free?</b></summary>

Yes, the builder is 100% free and open-source. There are no premium tiers, watermarks, or hidden fees. You can use it to generate unlimited embeds.
</details>

<details>
<summary><b>Does it support buttons or select menus?</b></summary>

Currently, it focuses on rich embeds. Support for interactive components (buttons, dropdowns) is planned for the next major version.
</details>

<details>
<summary><b>Can I use this for webhooks?</b></summary>

Yes! The export tab has a specific format tailored for Discord webhooks, making it perfect for integrations with GitHub, Notion, or custom scripts.
</details>

<details>
<summary><b>Does it save my embeds?</b></summary>

Yes, drafts are automatically saved in your browser's local storage. However, clearing your browser data will erase them, so make sure to copy the code when you're done.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include a screenshot of the bug and details on your browser version.
</details>
